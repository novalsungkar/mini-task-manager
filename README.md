# mini-task-manager
Aplikasi manajemen tugas (*task manager*) sederhana *End-to-End* yang dirancang dengan fokus pada pelacakan riwayat perubahan data (Audit Log) secara kronologis dan tidak dapat dimodifikasi.  ## 🛠️ Teknologi yang Digunakan * **Frontend:** React, Vite, TypeScript, Axios, CSS murni. * **Backend:** Node.js, Express, TypeScript, In-Memory Storage.
